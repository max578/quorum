# Contributing to quorum

Thanks for considering a contribution.

Please open an issue at <https://github.com/max578/quorum/issues> before
substantial changes. Keep pull requests focused, include tests for behaviour
changes, and describe user-visible impact in the PR body.

PR bodies should reference the issue they resolve with `Fixes #<n>` so the
issue auto-closes on merge. The issue tracker for this package is
<https://github.com/max578/quorum/issues>.

For institutional or co-owned work, do not change license, ownership,
attribution, or public-release status without maintainer approval.
