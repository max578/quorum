# Posterior-mean coefficients for a koine fit

Posterior-mean coefficients for a koine fit

## Usage

``` r
# S3 method for class 'flexybayes_koine'
coef(object, ...)
```

## Arguments

- object:

  A `flexybayes_koine` object.

- ...:

  Unused.

## Value

A named numeric vector of koine's synthesised posterior means.
